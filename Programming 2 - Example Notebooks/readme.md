## Programming 2 Example Notebooks

These notebooks were originally created in October-November 2025, following a major structural revision in October-November 2026 synchronised with the change in syllabus, and released to the students enrolled in the Programming 2 (BIOE50010, module leader: [Dr James J Choi](https://profiles.imperial.ac.uk/j.choi)) module at the Department of Bioengineering as the computer lab supplementary materials.

| Notebook | Description |
| --- | --- |
| N0 | A refresher on variables, data types, operators, strings and collections, indexing and slicing, mutability, and understanding error messages. |
| N1 | Examples of conditional statements (`if`-`elif`-`else`), loops (`for` and `while`), and defining reusable functions to organise your code. |
| N2 | You’ll explore list and string methods, practise looping with `range()`, `enumerate()` and `zip()`, and turn lists into strings and back again. |
| N3 | Examples of Python’s ability to read from and write to external files, and functions that accept a variable number of arguments. |
| N4 | The 1st notebook for OOP, demonstrating the syntax to define and use objects, and overload operators e.g., `+`, `*` for your defined data type. |
| N5 | The 2nd notebook for OOP, exploring potential relations between different classes in OOP, including inheritance and polymorphism. |
